## Default Permission

Read what is in the photo library and on shared storage, and ask for access to both.

#### This default permission set includes the following:

- `allow-access`
- `allow-ask`
- `allow-summary`
- `allow-files-access`
- `allow-ask-files`
- `allow-categories`
- `allow-category-files`
- `allow-share`
- `allow-open`
